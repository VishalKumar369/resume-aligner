**Tips**
- Use PNG, roughly 1400–1600px wide; keep each under ~500 KB if you can (compress large ones).
- Dark theme looks best for the dashboard and landing shots.
- Prefer screenshots without personal data you don't want public, or blur them first.
- Add more if you like (e.g. `readiness.png`, `skill-gaps.png`, `learning-roadmap.png`) and reference
  them from the README.
